# 车型版型对照表

本文件是「缤越助手」车型识别与版型展示的**唯一数据真源**。任何版型名称、排列顺序的调整，必须同时修改代码与本文档，避免两处漂移。

## 一、为什么要维护这张表

助手需要根据车机上报的车系标识，圈定该车系实际存在的版型，并在界面上让车主选择自己的配置。版型名称一旦写错（比如把「热擎」写成「热擎版」，或凭空造一个不存在的版型），车主会看到自己车上根本没有的选项，直接影响功能判断的可信度。

因此有两条硬约束：

1. **名称必须来自车厂官方命名**，不能自行归纳或简写；
2. **顺序必须由高到低排列**（按钮从左往右即高→低）。

## 三、展示规则

- **格式统一为 `[车型名] · [版型名]`**，例如 `缤越COOL · 热擎`。
- **严禁拼接年代款**：不要写成 `2022款 缤越COOL`，年代信息不进标题。
- **默认状态只显示车系/车型**（如 `缤越COOL`、`帝豪L`），版型在车主主动选择后才补充展示。
- **卡片标题统一叫「车型配置」**，不使用「车型配置档位」这类生硬技术词。
- **严禁使用「高配 / 中配 / 低配」代指版型**。描述按键差异时必须用真实版型名，例如「热擎：自定义按键；激擎 / Battle：微信 / 拍照」。
- **切换反馈**统一为「已切换车型配置为「XXX」」。

## 四、新增车型时的检查项

适配新车型时，按顺序确认：

1. 该车系是否已有平台代号；没有则先在代码中确认车机上报的实际标识。
2. 通过车机日志或实车核对**真实存在的版型全集**，不要照抄其他车系。
3. 按高→低顺序写入本文档表格，同步更新代码常量。
4. 确认版型切换不会影响缤越 COOL 基线逻辑（见 `geely-multi-vehicle-adapter-sop` 的物理隔离要求）。
