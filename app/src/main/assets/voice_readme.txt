======================================================
《缤越助手 · 车规级专属语音包制作与命名指南》
======================================================
适用车型：吉利缤越 COOL (SX11-A3 / E02) 及吉利全系车机

【核心升级特性】
自 1.7.48 版本起，车机已全面支持「中文命名」与「英文命名」智能双向识别匹配！
无论车友使用中文名字（如“主驾车门开启.mp3”、“动力已锁止【P】.mp3”）
还是官方英文名字（如“door_fl.mp3”、“gear_p.mp3”），车机导入时均可 100% 自动识别并绑定！

【音频文件格式与技术规格】
1. 支持格式：.mp3（强烈推荐）、.wav、.ogg、.aac、.m4a（必须为上述小写后缀扩展名）；
2. 采样率与声道：推荐 24,000Hz (24kHz) 或 44,100Hz (44.1kHz)，单声道/双声道，码率 48~128kbps；
3. 音频前置静音（车规关键红线）：
   每个音频文件开头必须保留 ≥280ms（约 0.3 秒）的静音！
   车机硬件功放从待机休眠到物理通路选通需要 0.2~0.3 秒建立时间，若音频从第 0 毫秒就开口发声，
   开头第一个字会被直接吃掉（如“运动模式”只听到“动模式”）。
   使用 ffmpeg 处理范例：
   ffmpeg -i 原音频.mp3 -af "adelay=280" -ar 24000 -ac 1 -b:a 48k 输出.mp3
   若使用剪辑软件（如剪映、Audacity 等），在音频最开头拖入 0.3 秒空白静音即可。

【打包、导入与生效方法】
======================================================
1. 将准备好的音频文件（支持中/英文文件名，数量任意，未提供的场景会自动保留默认官方原声兜底）
   全选后打成 .zip 压缩包（例如“蜡笔小新迎宾语音包.zip”）；

2. 把压缩包送进车机，两种方式任选其一：

   方式一（推荐，最省事）：手机扫码直接传
   车机打开【车载声音 ➔ 专属语音包】，点右上角【手机扫码制作】，
   用手机扫屏幕上的二维码，在手机网页里直接选整套语音包上传即可，不用插线、不用找 IP。

   方式二：走局域网无线快传
   手机开热点并让车机连上（注意：车机自己开的热点只能给手机上网，
   受原厂防火墙隔离，手机连不回车机后台，必须用手机开热点供车机连接）。
   车机打开【应用生态 ➔ 特权安装通道】，点【局域网无线快传】卡片扫码，
   在手机网页上传 .zip 压缩包即可。

3. 传完后，回到车机【车载声音 ➔ 专属语音包】，点【导入语音包 (.zip)】选刚传上去的压缩包，
   车机自动解压并完成别名探测绑定，整套即刻生效；

4. 想单独调某一个场景，可在【车载声音】里进入对应页签（换挡语音 / 驾驶模式 / 车门 / 电动尾门 / 前引擎盖），
   点该场景右侧的【声效设置】试听、微调音量增益或单独切换声道。

小贴士：上面对照表里一共 24 个场景，每个都自带官方原声，你只提供想改的那几个就行，
没提供的场景一律自动使用内置原声，不会变哑。
