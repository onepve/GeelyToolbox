======================================================
《吉利智驾 · 车规级专属语音包制作指南》
======================================================

【快速上手】
1. 准备好你想要使用的 MP3 音频文件（例如自己录音、影视原声、AI生成音频等）；
2. 将你的音频文件重命名为下方对应的 16 个标准英文文件名；
3. 直接替换本压缩包中的同名文件（无需创建额外文件夹，全部放在根目录）；
4. 全选所有文件，压缩为 .zip 格式（压缩包名称支持中文，例如“我的专属语音.zip”）；
5. 通过手机无线快传直接上传到车机，车机将自动识别并解压部署！

【16 个场景文件名对应表】
------------------------------------------------------
1. 挡位安全播报：
   gear_d.mp3          前进挡 (D挡) 播报
   gear_r.mp3          倒车挡 (R挡) 播报
   gear_p.mp3          驻车挡 (P挡) 播报
   gear_n.mp3          空挡 (N挡) 播报

2. 驾驶模式切换播报：
   mode_smart.mp3      智能模式播报
   mode_comfort.mp3    舒适模式播报
   mode_eco.mp3        经济模式播报
   mode_sport.mp3      运动模式播报

3. 四门迎宾与关门播报：
   door_fl.mp3         主驾开门播报
   door_fl_close.mp3   主驾关门播报
   door_fr.mp3         副驾开门播报
   door_fr_close.mp3   副驾关门播报
   door_rl.mp3         后排开门播报 (左后)
   door_rr.mp3         后排开门播报 (右后)

4. 原厂电动尾门播报：
   trunk_open.mp3      电动尾门升起开门播报
   trunk_close.mp3     电动尾门闭合关门播报
------------------------------------------------------

【注意事项与容错保护】
1. 格式要求：推荐标准 MP3 格式，采样率 44.1kHz 或 48kHz；
2. 时长建议：1~3 秒短音频最佳，干脆利落不拖沓；
3. 容错兜底机制：你不需要将 16 个音频全部放满！如果某个场景你没有录制，留空不放即可，车机会自动使用出厂自带的高品质晓晓原声补齐兜底，绝不会出现车机静音或哑巴的问题；
4. 自由混搭：导入车机后，你既可以一键“整套应用”，也可以在车身联动的【声效设置】里为不同挡位或车门单独选择不同的音频自由混搭！
