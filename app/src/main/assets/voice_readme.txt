《缤越助手 · 车规级专属语音包制作指南》
======================================================

【快速上手】
1. 准备好你想要使用的 MP3 音频文件（例如自己录音、影视原声、AI生成音频等）；
2. 模板压缩包内已预置了标准英文名的 0 字节占位文件，将你制作好的音频直接覆盖同名文件即可；
3. 未替换的 0 字节文件在导入车机时会自动跳过，绝不会覆盖你原有的单项自定义设置或官方原声；
4. 全选所有文件，压缩为 .zip 格式（压缩包名称支持中文，例如“我的专属语音.zip”）；
5. 通过手机无线快传直接上传到车机，车机将自动识别并解压部署！

【注意事项与容错保护】
0. 前置静音（必读！2026-09-18 新增规格）：每个 MP3 的开头必须保留 ≥280 毫秒的静音！
   车机功放从待机到出声需要约 0.2~0.3 秒建立声音通道，如果音频从第 0 毫秒就开口，
   开头第一个字会被直接吃掉（例如「运动模式」只听到「动模式」）。
   处理办法（装了 ffmpeg 的话一条命令搞定）：
   ffmpeg -i 你的音频.mp3 -af "adelay=280" -ar 24000 -ac 1 -b:a 48k 输出.mp3
   没有工具也可以在任意音频编辑软件里在开头拼一段 0.3 秒的静音；
1. 格式要求：推荐标准 MP3 格式，采样率 24kHz 或 44.1kHz（建议 24kHz 单声道 48kbps，与车机播报一致）；
2. 时长建议：1~3 秒短音频最佳，干脆利落不拖沓（时长已含前置静音）；
3. 容错兜底机制：你不需要将全部音频放满！如果某个场景你没有录制，留空不放即可，车机会自动使用出厂自带的高品质晓晓原声补齐兜底，绝不会出现车机静音或哑巴的问题；
4. 自由混搭：导入车机后，你既可以一键“整套应用”，也可以在车身联动的【声效设置】里为不同挡位或车门单独选择不同的音频自由混搭！
