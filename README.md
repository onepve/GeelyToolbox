## 核心基础功能一览

1. **全新 OnePve Design 极简美学架构 (Dark Glassmorphism)**：全面基于 Vite + Vue 3 + Tailwind CSS 纯组件化工程重构，采用深邃星空漫反射大底座、PPanel 同款亚克力微透悬浮卡片、日夜双模无缝自适应；
2. **黄金车规大磁贴与暖阳琥珀呼吸光环 (Halo Ring)**：按键高度精准收敛为 **84~88px 饱满大磁贴**（主字 21px 特粗、副字 15.5px 粗体紧凑充实），彻底拔除单键盲切循环，平铺直选，消除上下多余废白，文字保持默认高对比（夜间纯白/白天深墨黑），外圈点亮精致暖阳琥珀金光环；
3. **顶栏 PPanel 同款 12V 蓄电池电压流光微胶囊**：顶栏最左侧直出实时物理电压（`>=11.8V 绿色健康/充能`、`11.5~11.8V 橙色低电`、`<11.5V 红色高危`），发电机充放电动态感知，点击秒级联动呼出整车健康大看板；
4. **Android 9 布局防塌陷隔离铁律**：采用 `space-y-6` 实体隔离带替代现代 flex gap，彻底根除低版本 WebView 下按钮遮挡标题与说明文字的 Bug；
5. **车门底层物理状态翻转机 (State Flip) 与关门毫秒立断**：100% 锁定底盘 MCU 物理串口报文 (`91 02 01 b6/b7`)，开门即播、关门瞬间打断开门音频并无缝切入“车门已关好”；
6. **D 挡启程与 R 挡倒车安全语音播报**：监听底层 MCU 挡位报文，踩刹车挂入 D 挡温馨播报一路平安，挂入 R 挡倒车防碰撞安全提醒；P 挡与 N 挡绝对静默，天然免疫蓝牙靠近点亮误报；
7. **方向盘按键深度接管与米小江方控互斥协同**：屏蔽原厂收音机抢占，支持米小江优先、控制台独立接管（Mode 键与静音键短按秒切 360 环视或高德）、恢复原厂三态单选互斥，静音长按 10 秒纯硬件看门狗冷重启救砖 100% 保留；
8. **蓝牙 A2DP 音频免点直出通道与 U 盘自动感知**：监听手机蓝牙播放推流，自动申请系统音频焦点并压制原厂后台静音，手机一放歌车机音响秒出声；U 盘插入自动双轨广播识别并轻声提醒，全盘扫歌做成独立子开关且默认关闭；
9. **白名单永久锁死与原厂商店四步闭环冻结**：提权彻底冻结原厂应用商店（`com.ecarx.appstore`），清空缓存并注入白名单属性，结合整车完整冷重启锁死白名单；
10. **全栈 7 大 OnePve 车规级二级模态弹窗闭环**：彻底根除弹窗四周生硬黑色边框，设置大弹窗、ADB 终端、无线快传 8888 大二维码、双轨工程暗码直通、商城详情大窗口、改文字 TTS 与安全确认门禁全量组件化覆盖。
