## 🌟 核心功能特性

### 1. 深度方控按键接管与音源仲裁
* **MODE 键自定义与 360 退出防冒头**：按下方向盘 MODE 键毫秒级拉起 360 全景影像，同时执行底层前置清栈；挂载退出生命周期动态后置守护，倒车或全景退出露出原厂多媒体时瞬间清除并平滑回退桌面。
* **物理按键三键唤醒**：方向盘静音键、主页键、语音按键精准拦截与功能重映射。
* **方控切歌与音源仲裁**：方向盘切歌键（上一曲/下一曲/播放暂停）直接穿透分发；深度融合首选音源（手机蓝牙 / QQ音乐 / 网易云音乐等），恪守「连接不等于推流」契约，蓝牙仅连接待机时坚决不截胡三方播放器切歌，支持按键唤醒断点续播。

### 2. 车身状态与驾驶安全联动
* **车门开闭状态联动**：实时监听主驾、副驾及后排四门开闭状态，支持独立分门或通用模式语音播报。
* **挡位安全智能状态机**：挂入 P 挡驻车锁止、R 挡倒车、D 挡前进或 N 挡空挡时进行精准状态流转，内置防抖延时与瞬态切歌保护。
* **4 大专车驾驶模式**：舒适 (Comfort)、经济 (Eco)、运动 (Sport)、智能 (Smart) 驾驶模式独立识别与联动，专车锁定防串模式。
* **车辆下电熄火休眠**：毫秒级响应钥匙 OFF 熄火断电信号，状态机自动归零并平滑进入休眠。

### 3. 车载音频通道与 MAY_DUCK 焦点守护
* **硬件功放选通守护**：独创常驻 `MAY_DUCK` 焦点守护机制，彻底解决原厂伴听多媒体被冻结后，系统底层 AudioPolicy 物理静音硬件声卡导致蓝牙无声音的死穴。
* **静默蓝牙连接**：手机蓝牙连入时仅静默打通底层音频物理通道与焦点守护，坚决不自发 `play()` 抢播，尊重用户配置的首选音源。
* **微信语音与导航智能闪避**：微信语音与播报推流期间平滑压低媒体音量，播报结束后自动无缝恢复续播。

### 4. 手机无线快传与专属素材池 (免插 U 盘)
* **三大场景清晰导航**：车机一键生成二维码，手机免装 App 扫码直连，划分「极速快传 / 远程运维 / 车载语音」三大独立场景。
* **车载语音专属素材池直传**：手机端直接选择个性音效（`.mp3`）分片秒传至车机受保护素材池，车机端即点即绑，彻底告别插拔 U 盘拷文件的繁琐。
* **极速快传与安装引导**：支持手机端大文件 APK 高速无线推送，直通车载原生文件管理点选安装。
* **9 项车机远程运维**：手机端一键下发一键重启、屏幕唤醒、应用清理、日志提取等系统级指令，即点即达。

### 5. 特权 ADB 终端与云端精选商城
* **ADB 一键特权运维**：内置极速 TCP 长连接复用池（20~50ms 响应），新增一键激活第三方音乐软件（酷我/QQ音乐等）车载均衡器（EQ）特权胶囊。
* **100% 纯云端动态商城**：精选适配车机横屏的优质应用源（高德车机版、音乐软件、实用工具等），由云端动态维护与热更。
* **原厂拦截机制免还原**：一键安全冻结系统自带拦截机制与白名单验证，防止重启后第三方应用被系统静默清除。

### 6. 主舞台全量常驻与极速流畅体验
* **物理 0ms 纯粹秒开**：7 大功能大菜单（商城、方控、车身联动、车身设置、音频、系统维护、特权安装）开机全量挂载就绪常驻，全生命周期绝不二次重建，菜单切换 0ms 纯粹秒开。
* **本地媒体极速持久化缓存**：引入 localStorage 本地持久化缓存，彻底根除进入座舱智能页面时的同步扫盘卡死。
