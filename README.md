# 缤越助手 (GeelyToolbox)

专为 **吉利缤越 COOL**（及同架构缤瑞 COOL、帝豪 L 等吉利系车型）深度定制与实车调优的**车载多功能实用工具箱**。

解决自带车机无法自由安装软件、方向盘按键不能自定义、退出 360 全景弹窗抢屏幕、停用自带多媒体后蓝牙没声音等日常用车痛点。只要车机支持开启无线调试（WiFi ADB），即可直接无线安装使用，在后台安静守护。

## 🗺️ 5 大核心功能分类

1. **行车联动（方控/360）**
   - **方向盘按键自由改**：静音键、主页键、语音按键支持单击、双击、长按自由绑定打开软件或常用功能；切歌键精准控制当前播放器，不串手机。
   - **MODE 键秒开 360**：按一下方向盘 MODE 键立刻拉起 360 全景影像；退出 360 时直接干净返回桌面，绝不弹原厂多媒体抢屏幕。
   - **行车盲区自动调出 360**：起步挂 D 挡自动唤起 360 扫除盲区（车速超 15km/h 自动退出）；车速 ≤30km/h 打转向灯自动看侧方盲区，方向回正自动退。
   - **车速与大灯联动**：车速达到设定阈值自动播放音乐；夜间开大灯联动专属逻辑。
   - **网络与外设**：开机自动连手机热点或车载 Wi-Fi，外设蓝牙状态无感保活。

2. **车载声音（提示/语音）**
   - **换挡安全提醒**：挂入 P/R/N/D 挡实时大白话播报，红绿灯起步挂 D 挡迅速提醒，防止挂错挡。
   - **4 大驾驶模式旋钮联动**：转动旋钮，舒适、经济、运动、智能 4 种驾驶模式立刻语音播报。
   - **车门状态提醒**：支持四门独立分门播报（清晰报出哪扇门没关好），也可选极简合并播报；开机打火不乱报。
   - **电动尾门播报**：后备箱开启、关闭专属声音提醒。
   - **智能避让与蓝牙保活**：导航或微信语音响起时音乐自动淡化变小，播报完平滑恢复；即使停用车机自带的原厂多媒体，蓝牙依然正常放歌发声。
   - **专属语音包**：内置多种风格提示音，支持手机扫码导入个性化语音包。

3. **行程油耗（油价/账本）**
   - **实时油价日历**：每日自动同步全国 31 省市 92#/95#/0# 发改委最新指导价与调价预警。
   - **智能加油账本**：车机端随手记一笔（金额、升数、单价、里程），自动精准核算真实百公里油耗与花费趋势。

4. **应用生态（商城/安装）**
   - **专车精选云端商城**：严选适配车机横屏的高德地图、音乐与实用工具，纯云端动态更新，免去到处找安装包的烦恼。
   - **手机无线快传**：车机免插拔 U 盘，手机扫码无线直推 APK 安装包与语音包。
   - **解除安装限制**：一键放行白名单，彻底解决吉利车机重启后偷偷删除第三方软件的问题。
   - **整车应用管理**：系统自带卡顿应用冻结、解冻与无用组件精简。

5. **系统设置（桌面/外观）**
   - **桌面车况悬浮胶囊**：常驻桌面显示实时车速、挡位与小电瓶电压；自带闲置自动屏保。
   - **12V 小电瓶健康看板**：实时监测电瓶电压，预防亏电无法点火。
   - **双模质感主题**：白天浅色护眼、夜间深色防眩光，支持晴空蓝、极光青等 11 套车规高质感配色。
   - **车标与启动项**：车型版型显示微调，开机自启与默认首页自由设定。
   - **一键脱敏排障**：遇到问题一键抓取全量脱敏诊断日志，高速直传云端并自动生成 6 位识别码，交流群直接报码即可分析排查。
