## 🌟 核心功能特性

### 1. 深度方控按键接管与仲裁
* **MODE 键自定义与 360 退出防冒头**：按下方向盘 MODE 键毫秒级拉起 360 全景影像，同时执行底层前置清栈；挂载退出生命周期动态后置守护，倒车或全景退出露出原厂多媒体时瞬间清除并平滑回退桌面。
* **物理按键三键唤醒**：方向盘静音键、主页键、语音按键精准拦截与功能重映射。
* **方控切歌与音源仲裁**：方向盘切歌键（上一曲/下一曲/播放暂停）直接穿透分发；深度融合首选音源（手机蓝牙 / QQ音乐 / 网易云音乐等），蓝牙暂停状态下亦可直接按键唤醒播放。

### 2. 车身状态与驾驶安全联动
* **车门开闭状态联动**：实时监听主驾、副驾及后排四门开闭状态，支持独立分门或通用模式语音播报。
* **挡位安全智能状态机**：挂入 P 挡驻车锁止、R 挡倒车、D 挡前进或 N 挡空挡时进行精准状态流转，内置防抖延时与瞬态切歌保护。
* **4 大专车驾驶模式**：舒适 (Comfort)、经济 (Eco)、运动 (Sport)、智能 (Smart) 驾驶模式独立识别与联动，专车锁定防串模式。
* **车辆下电熄火休眠**：毫秒级响应钥匙 OFF 熄火断电信号，状态机自动归零并平滑进入休眠。

### 3. 车载音频通道与 MAY_DUCK 焦点守护
* **硬件功放选通守护**：独创常驻 `MAY_DUCK` 焦点守护机制，彻底解决原厂伴听多媒体被冻结后，系统底层 AudioPolicy 物理静音硬件声卡导致蓝牙无声音的死穴。
* **静默蓝牙连接**：手机蓝牙连入时仅静默打通底层音频物理通道与焦点守护，坚决不自发 `play()` 抢播，尊重用户配置的首选音源。
* **微信语音与导航智能闪避**：微信语音与播报推流期间平滑压低媒体音量，播报结束后自动无缝恢复续播。

### 4. 极速特权 ADB 与云端商城
* **常驻长连接复用池**：内置 TCP 长连接 Session 复用通道，彻底消除单次操作重复计算 2048 位 RSA 密码学签名的耗时瓶颈，应用冻结/解冻与特权指令下发达到 20~50ms 极速瞬间响应。
* **100% 纯云端动态商城**：商城架构全面解耦，精选适配车机横屏的优质应用源（高德车机版、音乐软件、工具等），由云端 `apps.json` 动态下发与热更维护。
* **原厂拦截机制免还原**：一键安全冻结系统自带拦截机制与白名单验证，防止重启后第三方应用被系统静默清除。

### 5. 个性化语音包定制
* **车规级前置静音规范**：内置标准车规级音频防吞音规范，支持自定义换挡、开关门、切换模式等语音提醒。
