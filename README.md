## 核心基础功能一览

1. **全新车规级 HMI 架构与 M3 暗黑微透毛玻璃 (Dark Glassmorphism)**：全面基于 Vite + Vue 3 + Tailwind CSS 纯组件化工程重构，采用深邃星空漫反射大底座、M3 亚克力悬浮透光卡片、日夜双模无缝自适应；
2. **菲茨定律 106px 饱满大触控矩阵与外圈鎏金呼吸光环**：主字 23px 特粗、副字 17.5px 粗体紧凑充实，彻底拔除单键盲切循环，平铺直选，操作按键全面扩充至 66~72px 巨型触控防颠簸误触，内置 Web Audio 机械微触控清脆声；
3. **车门物理状态翻转机 (State Flip) 与关门毫秒立断**：彻底拔除死板时间防抖锁，100% 锁定底盘 MCU 物理串口报文 (`91 02 01 b6/b7`)，开门即播、关门瞬间打断开门音频并无缝切入“车门已关好”；
4. **D 挡启程与 R 挡倒车安全语音播报**：监听底层 MCU 挡位报文，踩刹车挂入 D 挡温馨播报一路平安，挂入 R 挡倒车防碰撞安全提醒；P 挡与 N 挡绝对静默，天然免疫蓝牙靠近点亮误报；
5. **方向盘按键深度接管与米小江方控互斥协同**：屏蔽原厂收音机抢占，支持米小江优先、控制台独立接管（Mode 键与静音键短按秒切 360 环视或高德）、恢复原厂三态单选互斥，静音长按 10 秒纯硬件看门狗冷重启救砖 100% 保留；
6. **蓝牙 A2DP 音频免点直出通道**：监听手机蓝牙播放推流，自动申请系统音频焦点并压制原厂后台静音，手机一放歌车机音响秒出声，告别手动进入原厂多媒体点击蓝牙；
7. **USB 闪存盘插拔轻提醒与独立扫歌子开关**：插入 U 盘毫秒级识别挂载并轻声提醒，全盘歌曲后台检索扫描做成独立子开关且默认克制关闭，不越俎代庖；
8. **白名单永久锁死与原厂商店四步闭环冻结**：提权彻底冻结原厂应用商店（`com.ecarx.appstore`），清空缓存并注入白名单属性，结合真实硬件冷重启锁死白名单；
9. **顶栏 12V 蓄电池电压精准大看板**：大字直出实时物理电压，发电机充放电动态感知，车规三阶健康预警（>=11.8V 绿色健康 / 11.5~11.8V 橙色警戒 / <11.5V 红色亏电）；
10. **全栈 7 大 M3 车规级二级模态弹窗闭环**：设置大弹窗、ADB 终端、无线快传 8888 大二维码、双轨工程暗码直通、商城详情大窗口、改文字 TTS 自定义台词与安全防误触确认门禁全量组件化覆盖。
