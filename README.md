# 缤越助手 (GeelyToolbox)

专为 **吉利缤越 COOL**（亿咖通 E02 / IHU516 芯片，Android 9 车机系统）深度定制与实车调优的**车载多功能实用工具箱**。

只要车机支持开启无线调试（WiFi ADB），即可直接无线安装使用。它在车机后台安静运行，解决自带车机无法自由安装软件、方向盘按键不能自定义、退出倒车或全景时弹窗抢屏幕、停用自带多媒体后蓝牙没声音等日常用车痛点。

## 🚀 核心特性速览

### 1. 方向盘按键自定义与切歌
* **MODE 键自定义与 360 退出防抢屏**：按一下方向盘 MODE 键立刻打开 360 全景影像；退出 360 时直接干净返回桌面，不会弹出原厂多媒体抢屏幕。
* **常用按键自定义**：方向盘静音键、主页键、语音按键精准拦截，支持自由绑定常用应用或功能。
* **方向盘切歌控制**：方向盘切歌键精准控制当前正在播放的音乐软件，连着蓝牙也不会误触发手机切歌。

### 2. 车身状态感知与语音提醒
* **车门开闭状态联动**：开门关门语音提醒，刚打火开机不会胡乱补报上车动作。
* **换挡安全语音提醒**：挂入 P/R/D 挡立刻播报，红绿灯起步挂 D 挡迅速提醒，反应灵敏。
* **4 大专车驾驶模式**：舒适 (Comfort)、经济 (Eco)、运动 (Sport)、智能 (Smart) 驾驶模式独立识别与联动，转动模式旋钮立刻播报当前驾驶模式，反应迅速。

### 3. 车载蓝牙声音保活
* **蓝牙声音保活**：停用车机自带的原厂多媒体后，助手会自动保持车机声音通道畅通，手机蓝牙连上放歌依然正常发声。
* **微信语音与导航智能闪避**：导航播报或微信语音响起时自动调小背景音乐，播报完后自动恢复正常。

### 4. 行程油耗与全国油价看板
* **实时油价看板**：每日自动同步归属省份 92#/95#/0# 柴油最新发改委指导价与下轮调价趋势。
* **车载加油台账**：随时在车机端记录每次加油的金额、升数与当前里程，自动推算真实百公里油耗。

### 5. 专车精选云端商城与无线快传
* **100% 纯云端动态商城**：精选适配车机横屏的优质应用源（高德车机版、音乐软件、实用工具等），由云端持续更新，无需手动升级应用商店。
* **手机无线快传**：手机扫码即连，免插拔 U 盘，支持大文件 APK 高速无线推送与个性化语音素材秒传。
* **解除安装限制**：一键解除系统限制，防止第三方软件重启后被系统静默清除。

### 6. 车规级诊断日志与远程排障
* **一键脱敏抓取与原生流式直传**：本地 5 重深度脱敏（抹除手机号、导航轨迹与敏感位置，隐藏完整车架号，仅保留按键与底盘信号），原生流式高速直传云端，弱网环境不超时不卡死。
* **专属 8 位识别码与双列指引**：上传成功后弹窗以车规级双列呈现，自动生成专属 8 位识别码。车友反馈问题无需导出发送大文件，直接报 8 位识别码即可由作者调阅分析。
* **安全存储与自动焚毁**：云端加密存储仅保留 30 天供技术排障，到期全自动彻底物理销毁，杜绝隐私残留。
