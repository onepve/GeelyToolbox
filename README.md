## 核心基础功能一览

1. **白名单永久锁死与原厂商店治理**：提权彻底冻结原厂应用商店（`com.ecarx.appstore`），杜绝开机自动重置，实现第三方应用永久放行；
2. **高德地图 8.5 旗舰版安全直装**：解除签名限制，在控制台内下载后直接调起原生文件管理安装（支持 1280x480 仪表飞屏与红绿灯读秒，普通用户无需卡主题）；
3. **顶栏 12V 蓄电池电压自适应微胶囊**：实时直出小电瓶精确电压、发电机充放电状态与车规三阶预警（>=11.8V 绿色健康 / 11.5~11.8V 橙色警戒 / <11.5V 红色重度亏电），彻底杜绝熄火听歌导致电瓶亏电抛锚；
4. **整车供电与传感器实时健康看板**：点击顶栏微胶囊即可呼出大窗口，展示 12V 蓄电池状态、发电机供电感知、座舱车外 PM2.5 空气质量对比与当前专车通信协议；
5. **专车专用自适应架构与纯净五门智能语音**：冷启动自动识别硬件指纹并锁定车型（吉利缤越 COOL 2022款 · 1.5TD 激擎版 / 星瑞 / 通用协议），支持主驾/副驾/左后/右后四门迎宾与原厂电动尾门抬起/锁紧播报，出厂内置微软晓晓温婉知性声线（彻底拔除蓝牙钥匙心跳连报与转向灯冲突）；
6. **小爱语音引擎自感知激活**：自动检测车机小爱 TTS 引擎并在底层自动设为系统默认，无需进入被原厂屏蔽的系统设置即可实现打字自定义台词实时朗读；
7. **手机无线快传互联**：微信或相机扫描 8888 端口二维码，手机端免打字直接推送超长下载链接或无线投送本地 APK 至车机；
8. **精选车载软件中心**：动态同步云端 16 款经过真车实测适配的纯净车载应用（车载音乐、方向盘切歌助手、原生系统设置等）；
9. **高阶专家模式卡主题向导**：为进阶玩车党保留兔子时钟替换法通道，附带 5 秒强制倒计时防变砖安全锁，用于安装特定第三方魔改地图。
