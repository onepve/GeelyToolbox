## 🚀 核心特性速览

### 1. 深度方控按键接管与音源仲裁
* **MODE 键自定义与 360 退出防冒头**：按下方向盘 MODE 键毫秒级拉起 360 全景影像，同时执行底层前置清栈；挂载退出生命周期动态后置守护，倒车或全景退出露出原厂多媒体时瞬间清除并平滑回退桌面。
* **物理按键唤醒**：方向盘静音键、主页键、语音按键精准拦截与功能重映射。
* **方控切歌与音源仲裁**：方向盘切歌键（上一曲/下一曲/播放暂停）直接穿透分发；深度融合首选音源，蓝牙仅连接待机时坚决不截胡三方播放器切歌，支持按键唤醒断点续播。

### 2. 车身状态与驾驶安全联动
* **车门开闭状态联动**：实时监听主驾、副驾及后排四门开闭状态，标准车规播报，开机历史动作毫秒级丢弃，彻底杜绝开机倒灌补报。
* **挡位安全智能状态机**：挂入 P 挡驻车锁止、R 挡倒车、D 挡前进或 N 挡空挡时进行精准状态流转；红绿灯踩刹车空挡推入前进挡严格 0ms 瞬发播报，按 P 键 100% 灵敏播报驻车挡。
* **4 大专车驾驶模式**：舒适 (Comfort)、经济 (Eco)、运动 (Sport)、智能 (Smart) 驾驶模式独立识别与联动；固化出厂默认智能模式基准，开机后第一次转动物理旋钮 100% 手落声起。

### 3. 车载音频通道与硬件选通守护
* **硬件功放选通守护**：独创常驻音频焦点守护机制，彻底解决原厂伴听多媒体被冻结后，系统底层 AudioPolicy 物理静音硬件声卡导致蓝牙无声音的死穴。
* **微信语音与导航智能闪避**：微信语音与播报推流期间平滑压低媒体音量，播报结束后自动无缝恢复续播。

### 4. 行程油耗与全国油价看板
* **实时油价看板**：每日自动同步归属省份 92#/95#/0# 柴油最新发改委指导价与下轮调价趋势。
* **车载加油台账**：随时在车机端记录每次加油的金额、升数与当前里程，自动推算真实百公里油耗。

### 5. 专车精选云端商城与无线快传
* **100% 纯云端动态商城**：精选适配车机横屏的优质应用源（高德车机版、音乐软件、实用工具等），由云端动态维护与热更。
* **手机无线快传**：手机扫码即连，免插拔 U 盘，支持大文件 APK 高速无线推送与个性化语音素材秒传。
* **特权 ADB 运维**：一键安全冻结系统自带拦截机制与白名单验证，防止重启后第三方应用被系统静默清除。
